# DOC SOP Quizzes

A Flask quiz website for San Andreas Department of Corrections SOP and 10-code practice.

## Quiz Sections

- Corrections Officer Quiz
- Solo Patrol Quiz
- 10-Codes Quiz
- Full SOP Quiz

## Supervisor Panel

Supervisors can log in from the site header. Set `SUPERVISOR_PASSWORD` in hosting to change the supervisor password. If it is not set, the default local password is `DOC2026!`.

For the live Render site, keep both `SECRET_KEY` and `SUPERVISOR_PASSWORD` set as environment variables. `SECRET_KEY` can be generated by Render; `SUPERVISOR_PASSWORD` should be entered privately in the Render dashboard.

## Run Locally

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
flask --app app run --debug
```

Open `http://127.0.0.1:5000`.

## Edit Questions

Quiz questions live in `app.py`. The 10-code bank is in `CODE_ENTRIES`, SOP questions are in `SOP_QUESTIONS`, and the visible quiz sections are configured in `QUIZZES`.

## Deploy

Render can deploy this repo with:

```text
Build Command: pip install -r requirements.txt
Start Command: gunicorn app:app
```
